# Relik — Android-оболочка (Capacitor)

Проверочная сборка для телефона. **Публичного релиза нет** — он запланирован на 2027.
Цель этого этапа: проверить на живом Android пуши, TTL, отложенные, звонки и медиа.

## Что нужно на машине

1. **Node.js 20+** — `node -v`.
2. **JDK 17** — `java -version` (Android Gradle Plugin 8.x требует 17).
3. **Android Studio** (SDK Platform 34, Build-Tools, эмулятор или USB-телефон с отладкой).

Проверка: `adb devices` должен показать устройство.

## Сборка (первый раз)

```powershell
cd C:\67\relik\mobile
npm install
npm run add:android      # создаёт папку android/ (один раз)
npm run sync             # копирует сайт в www/ и синхронизирует android/
npm run open             # открывает проект в Android Studio
```

В Android Studio: **Run → Run 'app'** (или `gradlew.bat assembleDebug`).
APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Быстрая разработка без пересборки

В `capacitor.config.json` можно временно добавить:

```json
"server": { "url": "http://192.168.1.10:8096", "cleartext": true }
```

`192.168.1.10` — IP компьютера в локальной сети, `py -m http.server 8096` в корне сайта.
Тогда правки в коде видны сразу после перезагрузки приложения. Перед сборкой релиза
блок `server` нужно убрать.

## Что проверить на телефоне (чек-лист)

- [ ] Вход паролем, восстановление сессии после перезапуска приложения.
- [ ] Восстановление ключа фразой (12 слов) на «чистом» устройстве.
- [ ] Push: сообщение от второго аккаунта при закрытом приложении.
- [ ] TTL: сообщение исчезает, когда приложение закрыто (сейчас таймеры живут
      только в открытом приложении — это ожидаемое ограничение до P1).
- [ ] Отложенное сообщение уходит после открытия приложения.
- [ ] Звонок: слышимость, переключение камеры, демонстрация экрана.
- [ ] Медиа: фото, видео, голосовое, скачивание файла.
- [ ] PIN: блокировка после сворачивания на 60+ секунд.
- [ ] Поворот экрана и режим планшета.
- [ ] RU/EN в настройках, тёмная/светлая тема.

## Push

Web Push из `scripts/push-service` в APK **не работает** — нужен нативный FCM
(`@capacitor/push-notifications` + `google-services.json` из Firebase).
До 2027 достаточно проверять пуши в PWA (Chrome/PWA на Android, iOS 16.4+ «на экран»).

## Ограничения текущего этапа

- `www/` и `android/` не коммитятся (см. `.gitignore`).
- Иконка и splash пока стандартные Capacitor — заменить перед релизом.
- Плагин push установлен, но не инициализирован в коде: включаем на этапе релиза,
  чтобы не тащить Firebase-конфиг в публичный репозиторий.
