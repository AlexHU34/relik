# Relik — QA-чеклист (голос, звонки, чат, PWA)

Как пользоваться: открывайте пункты по порядку, отмечайте `[x]` при успехе.
Если что-то падает — приложите JSON-отчёт из `tools/diagnostics.html`
(кнопка «Скопировать отчёт»).

## 0. Подготовка

- [ ] Приложение открыто через локальный сервер (`http://localhost:8096`), не через `file://`
- [ ] Открыт `tools/diagnostics.html` — все критичные API зелёные
- [ ] Разрешение на микрофон выдано (иконка замка в адресной строке)
- [ ] Демо-вход выполнен (любой email + пароль от 6 символов)

---

## 1. Инструмент диагностики (`tools/diagnostics.html`)

- [ ] «Проверить микрофон» → полоска реагирует на голос
- [ ] Список устройств ввода отображается
- [ ] «Записать 3 секунды» → появляется плеер, запись слышна
- [ ] Скачивание записи работает
- [ ] «Тестовый звонок (loopback)» → статус `connected` < 3 с, полоска реагирует
- [ ] «Завершить» останавливает звонок (статус больше не меняется)
- [ ] «Проиграть тон 440 Гц» → слышен короткий сигнал
- [ ] «Скопировать отчёт» → буфер обмена содержит JSON

## 2. Голосовые сообщения в чате

- [ ] Нажать и удерживать микрофон → появляется индикатор записи и таймер
- [ ] Отпустить → голосовое отправляется и появляется в ленте
- [ ] Воспроизведение: ▶ запускает анимацию волн, повторный клик — пауза
- [ ] Длительность отображается в формате `м:сс`
- [ ] Запись короче 1 секунды не отправляется (не создаёт мусор)
- [ ] После отправки поле ввода снова активно
- [ ] При отказе в доступе к микрофону — понятная ошибка, приложение не падает

## 3. Звонки (после реализации WebRTC)

- [ ] Кнопка звонка в шапке чата инициирует вызов
- [ ] Собеседник видит входящий и может принять/отклонить
- [ ] Слышимость в обе стороны, задержка < 300 мс
- [ ] Mute микрофона работает (индикатор меняется)
- [ ] Завершение звонка закрывает сессию у обоих
- [ ] Повторный звонок после завершения работает
- [ ] Обрыв сети → переподключение или понятная ошибка
- [ ] Эхо отсутствует при использовании наушников
- [ ] Loopback-тест в диагностике проходит (см. п.1)

## 4. Базовый чат

- [ ] Вход/выход (демо), состояние сохраняется после перезагрузки
- [ ] 4 демо-чата, превью последнего сообщения и время корректны
- [ ] Поиск по чатам фильтрует список
- [ ] Открытие чата: шапка (имя/статус), история, автоскролл вниз
- [ ] Отправка текста: Enter — отправить, Shift+Enter — перенос строки
- [ ] Ответ (reply): цитата в композере и в сообщении, переход к оригиналу
- [ ] Реакции: 6 быстрых, счётчик, повторный клик снимает реакцию
- [ ] Редактирование: текст меняется, метка «изменено»
- [ ] Удаление: сообщение заменяется на «Сообщение удалено»
- [ ] Копирование текста в буфер
- [ ] Фото: открывается лайтбокс, закрывается X / кликом по фону / Esc
- [ ] Файл: имя и размер отображаются
- [ ] Галочки: одна — отправлено, две синие — прочитано

## 5. Группы

- [ ] «Новый чат» → «Создать группу»
- [ ] Список контактов заполнен, поиск работает
- [ ] Выбор участников: чипы появляются, удаление чипа работает
- [ ] Кнопка «Создать группу» без названия/участников — понятная ошибка
- [ ] После создания открывается групповой чат, шапка «участники: N»
- [ ] Группа появляется в списке чатов

## 6. Модальные окна и навигация

- [ ] Настройки: открываются, закрываются X / фоном / Esc
- [ ] Новый чат: то же
- [ ] Создание группы: то же
- [ ] Лайтбокс: то же
- [ ] Возврат из чата на мобильном (кнопка «назад»)
- [ ] Переключение RU/EN: все видимые строки меняются без перезагрузки
- [ ] После выхода URL ведёт на экран входа

## 7. Приветствие

- [ ] Экран входа: «Welcome to Relik!» появляется побуквенно, курсивом
- [ ] Пустой чат: то же приветствие + мигающий курсор
- [ ] При быстром повторном входе нет дублей/ошибок анимации

## 8. PWA и офлайн

- [ ] Манифест подхватывается (DevTools → Application → Manifest)
- [ ] Иконки 192/512 отображаются
- [ ] Service worker активен (Application → Service Workers)
- [ ] После первого визита приложение открывается офлайн
- [ ] Установка на телефон/десктоп предлагается

## 9. Хранилище и стабильность

- [ ] Данные сохраняются после перезагрузки (IndexedDB)
- [ ] Очистка данных сайта → приложение снова засеивает демо-чаты
- [ ] Нет ошибок в консоли при обходе основных сценариев
- [ ] Нет «застрявших» оверлеев (крестики закрывают всё)
- [ ] Приватный режим браузера (IndexedDB недоступен): приложение открывается, работает до перезагрузки
- [ ] Раскладка подстраивается сама: узкое окно → телефон, среднее → планшет, широкое → компьютер

## 9a. Запуск и «белый экран»

- [ ] Сразу видна тёмная заглушка «Загружаем приложение…», а не белое полотно
- [ ] Заглушка исчезает, как только показан экран входа (не ждёт ответа Supabase)
- [ ] При `offline` в DevTools → Network: заглушка с текстом «Нет подключения к интернету» и кнопкой «Обновить»
- [ ] Блокировка `*.supabase.co` (или VPN off) → тост «Нет связи с сервером Relik»
- [ ] Старый браузер без ES-модулей → сообщение «Браузер не поддерживает современный JavaScript»
- [ ] Битая ссылка на скрипт (DevTools → Block request URL) → на заглушке видна ошибка и кнопка «Обновить»

## 10. Производительность

- [ ] Первый рендер < 1.5 с на локальном сервере
- [ ] Прокрутка длинной ленты плавная (60 fps)
- [ ] Отправка сообщения — визуальный отклик < 100 мс
- [ ] Память не растёт бесконечно при переключении чатов

## 11. Кросс-браузер

- [ ] Chrome/Edge (desktop)
- [ ] Firefox (desktop)
- [ ] Safari (desktop)
- [ ] Chrome Mobile (Android)
- [ ] Safari / PWA (iOS 16.4+)
