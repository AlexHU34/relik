Diagnostics

dev

Самопроверка браузера для голосовых сообщений и звонков Relik. Откройте через локальный сервер (http/https), не через file://.

Поддержка API

Что умеет этот браузер. Красное — критично для звонков; жёлтое — необязательно.

Микрофон

Проверка разрешения, устройства и живой уровень сигнала.

не запущено
Говорите в микрофон — полоска должна двигаться. Если она на нуле, проверьте разрешение (иконка замка в адресной строке) и выбранное устройство ввода.

Запись голосового (3 сек)

Реальная запись через MediaRecorder и воспроизведение — то, что использует композер Relik.

не запущено
Скачать запись

Тестовый звонок (loopback)

Настоящая WebRTC-сессия сама с собой: проверяет микрофон, кодеки, ICE и воспроизведение удалённой дорожки — весь конвейер звонка.

не запущено
Если соединение «connected» и полоска реагирует на голос — канал звонка в порядке. Эхо — нормально для loopback (вы слышите себя).

Динамики / наушники

Короткий тон 440 Гц проверит вывод звука.

Отчёт

Скопируйте JSON-отчёт (поддержка API, устройства, mime-типы, результат звонка) — удобно приложить к баг-репорту.
