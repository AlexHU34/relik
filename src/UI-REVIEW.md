# UI-аудит Relik — итерация 1 (27.10.2026)

Как проводился: `scripts/ui-shots/shots.mjs` снял 11 экранов (ПК 1440×900,
iPhone 390×844, планшет 768×1024), затем интерфейс оценивался по скриншотам
и через внешний ИИ в браузере. Gemini без входа вернул ошибку 1060, поэтому
использован Duck.ai (GPT-6 Luna) — с приложенным скриншотом телефона.

## Что исправлено

| Проблема | Было | Стало |
|---|---|---|
| Мелкий и блёклый служебный текст | время 10,5px, `--tx-3:#5f6879` (≈3,2:1) | 11,5px, `#7b8496` (≈4,5:1) |
| Аватар входящего «плавал» у низа пузыря | `align-self:flex-end` | `flex-start` + отступ 3px |
| Шапка чата просвечивала сообщениями | rgba(…, .8) + blur; на телефоне blur отключён | плотный `var(--surface)` |
| Разделитель даты сливался с фоном | `surface-2` + `tx-3` | `surface-3` + `line-2` + плавный скрим |
| Подрезанное сверху сообщение «резалось» | жёсткий край | мягкое затухание 22px (mask) |
| Шапка телефона занимала много места | аватар 42px, иконки 38px | аватар 36px, иконки 40px |
| Пузыри на телефоне слишком узкие | 76% | 84%, компактнее padding |
| Кнопки без явного disabled-состояния | выглядели «мёртвыми» без объяснения | прозрачность .5 + курсор + без тени |
| Открытые окна не закрывались при переходе | профиль/настройки висели над новым чатом | `closeTransientOverlays()` на `hashchange` и Esc |
| Пустой список при первой загрузке | белый экран | скелетоны с shimmer-анимацией |
| **Критично:** вложенный `export` в `modals.js` ронял загрузку приложения | `SyntaxError: Unexpected token 'export'` на старте | функция вынесена на верхний уровень; проверено загрузкой в браузере на обоих вьюпортах |
| Поле ввода на телефоне низкое | ~44px | min-height 48px, зоны нажатия 40–42px |
