## Этап 1 — скорость загрузки

- [x] 1.1 Ленивый SDK: `js/backend/sdk.js`, `ensureClient()` во всех входных
  точках, режим по ключам (`HAS_BACKEND`), в демо SDK не грузится.
- [x] 1.2 preconnect/dns-prefetch к Supabase уже были — проверены.
- [x] Попутно: убраны `modulepreload` для `chatView/messages/auth` — они тянули
  ~116 KB кода чата на экран входа (Vite переписывал их в ленивый чанк).
- [ ] 1.3 Инлайн критического CSS — не делали: после 1.1 CSS на проводе
  ~19.6 KB gzip, а FCP упирается в TTFB GitHub Pages (1.4 с). Выигрыш меньше
  риска сломать визуальные регрессы.
- [ ] 1.4 `content-visibility: auto` для ленты — окно и так 120 узлов (13 мс
  рендер), а `contain-intrinsic-size` рискует сломать scroll anchoring и
  «прыжок в сообщение». Отложено до реальных жалоб на длинные чаты.

## Этап 2 — скорость интерфейса

- [x] 2.1 Виртуализация по факту есть: `js/ui/msgWindow.js` держит в DOM
  последние `PAGE_SIZE=120`, «показать раньше» догружает по 120. Измерено:
  2000 сообщений → 120 узлов, 60 fps (см. таблицу).
- [x] 2.2 Инкрементальный рендер есть: `appendToFeed()` дописывает только новые
  узлы (realtime, опрос, отправка), полная перерисовка — только когда это
  действительно нужно (поиск, баннеры, смена окна).
- [x] 2.3 Батчинг: realtime/опрос приходят пачками и дописываются одним
  `insertAdjacentHTML`; `requestAnimationFrame` уже используется для анимаций и
  скролла.
- [x] 2.4 Утечки при смене чата: `stopActiveSync()` чистит интервал, `activeSync`
  регистрируется через `js/ui/activeSync.js`, объектные URL медиа освобождаются
  (`clearMediaObjectUrls`). Отдельного heap-теста на 20 переключений нет.

Итог: пункты 2.x в этом коде уже были реализованы до плана; ценность работы —
их измерение и жёсткий бюджет в `perf-chat.mjs` (`DOM ≤ 160`, p95 ≤ 120 мс,
fps ≥ 30).

- [x] 3.3 Realtime: `js/backend/realtimeSub.js` отдаёт статус канала,

  и открытый чат. Страховка: опрос превью 10 с, синк чата 4–15 с.
- [x] 3.4 Офлайн-баннер (`initNetBar`), outbox с автоповтором по `online`/фокусу,

## Как проверять после изменений

```bash
cd relik
node scripts/check-all.mjs                     # 101 тест + типы + линтер + бюджеты
node scripts/build.mjs && node scripts/check-dist.mjs
node scripts/perf.mjs --profile slow3g --check # время и байты первого экрана
node scripts/perf-chat.mjs --msgs 2000 --check # окно DOM, p95, fps
node scripts/e2e.mjs --demo --url http://localhost:8096/
python -m http.server 8096 --directory dist    # перед запуском e2e/perf
```

Обновлять базы только осознанно:
`check-dist.mjs --write-baseline`, `perf.mjs --write`, `perf-chat.mjs --write`.
