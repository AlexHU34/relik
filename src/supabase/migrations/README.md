# Миграции схемы

Правило: **каждое изменение БД — файл в этом каталоге**. Порядок — по имени (дата + номер).
Все миграции идемпотентны: повторный запуск не ломает данные.

## Как применять

1. Supabase → SQL Editor → вставить файл целиком → Run.
2. Или через локальные креды: `py secrets/sqlrun.py supabase/migrations/<файл>.sql`
   (если скрипт есть в `secrets/`; секреты берутся из `secrets/cred.py`).
3. Проверить, что записалось:
   ```sql
   select * from public.schema_version order by applied_at desc limit 10;
   ```

## Правила

- **Не менять** уже применённые файлы — только новые.
- Удаление колонок — отдельным файлом с датой и пометкой в `note`.
- Файлы из корня `supabase/*.sql` — исторические (v1.x). Новые изменения — только здесь.
